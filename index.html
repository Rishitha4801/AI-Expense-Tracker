    Questions

    Does my data leave my device?

    No. Categorization and insights run in your browser. There is no account and no server, so nothing is uploaded.

    How does the AI learn my categories?

    Each time you add an expense, it remembers which words went with which category and uses them to weigh future suggestions. Pick a different category and the next suggestion reflects that.

    Where is my data saved?

    In your browser’s local storage. It stays when you reopen the file in the same browser, but it doesn’t sync between devices. Use Export CSV to back it up.

    Does it work offline?

    Yes. It’s a single file with no external dependencies.
